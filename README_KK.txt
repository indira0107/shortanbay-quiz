ШОРТАНБАЙ QUIZ — GITHUB PAGES НҰСҚАСЫ
======================================

Бұл жинақта студенттерге арналған онлайн тест, оқытушы кабинеті және Google Apps Script серверінің коды бар.

ФАЙЛДАР
- index.html — студенттер ашатын негізгі тест беті.
- admin.html — оқытушы кабинеті.
- Code.gs — Google Apps Script серверлік коды.
- README_KK.txt — осы нұсқаулық.

ЖҰМЫС ЛОГИКАСЫ
- 20 сұрақ.
- Өлең мазмұнына қатысты сұрақтарға 30 секунд, қалған сұрақтарға 20 секунд.
- Әр тест жүктелгенде әр сұрақтың жауап нұсқалары кездейсоқ ретпен беріледі.
- Уақыт біткенде жауап таңдалмаса, сұрақ жауапсыз өткізіледі; ол қате жауап ретінде есептеледі.
- Дұрыс жауаптар браузерге берілмейді, бағалау Apps Script серверінде орындалады.
- Нәтижелер Google Sheets-ке сақталады.
- Оқытушы кабинеті құпиясөз және уақытша серверлік сессия арқылы қорғалған.

1. GOOGLE SHEETS ЖӘНЕ APPS SCRIPT СЕРВЕРІН ДАЙЫНДАУ
1) https://script.google.com сайтына кіріңіз.
2) New project таңдаңыз.
3) Жобадағы Code.gs файлының ішін толық өшіріп, осы архивтегі Code.gs мазмұнын қойыңыз.
4) Save басыңыз.
5) Функциялар тізімінен setup функциясын таңдап, Run басыңыз. Алғашқы іске қосқанда Google сұраған рұқсаттарды беріңіз.
6) Execution log журналынан жасалған Google Sheets кестесінің сілтемесін көресіз. Сол кестеде нәтижелер сақталады.
7) Сол жақтағы Project Settings → Script Properties бөліміне өтіңіз. Add script property арқылы: Name = ADMIN_PASSWORD, Value = өзіңіз ойлап тапқан күрделі құпиясөз енгізіңіз.
8) Deploy → New deployment → Web app таңдаңыз.
9) Execute as: Me; Who has access: Anyone (егер Google Workspace әкімшісі рұқсат етсе) деп орнатыңыз.
10) Deploy басып, Web app URL мекенжайын көшіріңіз. URL әдетте /exec деп аяқталады.

2. API URL МЕКЕНЖАЙЫН ЕНГІЗУ
1) index.html файлын мәтіндік редакторда ашыңыз.
2) Бұл архивте index.html және admin.html файлдарының API_URL мәндері сіз берген Google Apps Script Web app URL мекенжайымен алдын ала толтырылған. Қайта енгізудің қажеті жоқ.
3) Егер Apps Script-те жаңа deployment жасап, жаңа URL алсаңыз, екі HTML файлындағы API_URL мәнін де жаңартыңыз.
4) Екі файлды да сақтаңыз.

3. GITHUB PAGES АРҚЫЛЫ ЖАРИЯЛАУ
1) GitHub-та жаңа Public repository жасаңыз. Мысалы, shortanbay-quiz.
2) Репозиторийдің негізгі (root) бумасына ТЕК index.html және admin.html файлдарын жүктеңіз.
3) Code.gs файлын GitHub-қа жүктемеңіз: ол серверлік код және Google Apps Script жобасында ғана қалуы керек.
4) Репозиторийде Settings → Pages бөліміне кіріңіз.
5) Build and deployment бөлімінде Source: Deploy from a branch таңдаңыз.
6) Branch: main, Folder: /(root) орнатып, Save басыңыз.
7) GitHub жариялаған URL мына үлгіде болады: https://USERNAME.github.io/REPOSITORY/

4. САЙТТЫ ҚОЛДАНУ
- Студенттерге негізгі URL-ді жіберіңіз: https://USERNAME.github.io/REPOSITORY/
- Оқытушы кабинеті: негізгі URL соңына admin.html қосыңыз.
  Мысалы: https://USERNAME.github.io/REPOSITORY/admin.html
- Оқытушы ADMIN_PASSWORD ретінде орнатқан құпиясөзбен кіреді.
- Жаңарту батырмасы Google Sheets-тен соңғы нәтижелерді қайта жүктейді.

5. МАҢЫЗДЫ ТЕКСЕРУ
- Алдымен сайтты өзіңіз тест ретінде толық өтіп көріңіз.
- Google Sheets ішінде тест нәтижесі пайда болғанын тексеріңіз.
- admin.html бетінде сол нәтиже көрінетінін тексеріңіз.
- Егер «Серверге қосылу мүмкін болмады» қатесі шықса, API_URL дұрыс енгізілгенін және Apps Script deployment қолжетімділігі Anyone екенін тексеріңіз.
- Code.gs өзгертілгеннен кейін Apps Script ішінде Deploy → Manage deployments → Edit арқылы жаңа нұсқаны Deploy ету қажет болуы мүмкін.
- Егер жаңа deployment URL берілсе, index.html және admin.html ішіндегі API_URL мәндерін жаңартыңыз.

ҚАУІПСІЗДІК
- ADMIN_PASSWORD мәнін HTML файлдарына немесе GitHub репозиторийіне жазбаңыз. Ол тек Apps Script → Script Properties ішінде сақталуы керек.
- Code.gs файлын ашық GitHub репозиторийіне салмаңыз.
- Google Sheets сілтемесін студенттерге таратпаңыз. Кесте иесінің Google аккаунтында сақталсын.
- Бұл үлгі серверлік тексеру мен парольдік кіруді қолданады, бірақ оны университеттің дербес деректерді қорғау талаптарына сәйкестігін тексермей, сезімтал деректерге пайдаланбаңыз.

ЕСКЕРТУ
Apps Script Web app URL және GitHub репозиторий URL пайдаланушы аккаунтында жасалғаннан кейін ғана белгілі болады. Сондықтан бұл архивте оларды өз деректеріңізбен толтыратын орын қалдырылған.
